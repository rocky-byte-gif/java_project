OOP Lab Practicals Mapping (Practical 1 to 10)

Practical No. Concept Class and Method where Used
Practical 1 Syntax and Control Flow: if-else, switch-case, loops, type casting, main entry Main.main() (entry point), ClinicService.getBillStatusCounts() (switch-case on status), Person.setAge() (if-else validation), Bill.calculateTotal() (type casting (double))
Practical 2 Arrays and Vector Collections: 1D arrays, Vector methods (add, remove, insertElementAt, size, capacity) Doctor.booked (boolean[] of 6 slots), Doctor.slotTimes (String[] array), ClinicService.getBillStatusCounts() (int[3] array), ClinicService.patients and waitingList (Vector operations)
Practical 3 Classes, Objects, Inheritance and Constructors: default, parameterized, abstract base class Person (abstract base), Patient extends Person, Doctor extends Person, MedicalRecord, Appointment, Bill
Practical 4 Interfaces, Method Overloading and Method Overriding: multiple interface implementation, encapsulation Interfaces Bookable, Billable, Reportable; Doctor implements Bookable, Reportable; Overriding getRole(); Overloaded addPatient(...) and bookSlot(...); Private fields with validated getters/setters
Practical 5 Java Package Organization and Import Directives Packages: medisync.model, medisync.exception, medisync.service, medisync.db, medisync.web
Practical 6 Keywords: this, super, static, final and Nested Classes Person() (this() chaining), Patient() (super() call), Bill.Builder (nested static class returning this), Patient.counter and Bill.counter (static), Doctor.SLOTS_PER_DOCTOR (final constant), Person.getDisplayName() (final method)
Practical 7 Exception Handling: custom checked exceptions, throw, throws, try-catch-finally PatientNotFoundException, SlotNotAvailableException, InvalidPatientException, InvalidBillException; ClinicDao (try-catch-finally resource closing)
Practical 8 Multithreading & Synchronization: Thread class, Runnable interface, synchronized methods/blocks, sleep, join BookingThread extends Thread, WaitlistTask implements Runnable (daemon thread), Doctor.bookSlot() (synchronized method), RushBookingHandler (8 threads with join())
Practical 9 String Handling: core String class methods Patient.validateId() (startsWith, split, length, substring), Person.getDisplayName() (charAt, toUpperCase, substring, toLowerCase), ClinicService.searchPatients() (toLowerCase, contains), WebServer (trim, indexOf, equalsIgnoreCase, concat)
Practical 10 Database Connectivity (JDBC): PreparedStatement, ResultSet, CRUD operations ClinicDao: savePatient(), deletePatient(), loadPatients(), loadDoctors(), saveAppointment(), saveRecord(), saveBill(), getBillsByStatus()
